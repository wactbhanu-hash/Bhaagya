# भाग्य 1.0 Build-Ready Package

The project contains the V7 calculation/evidence architecture plus release documentation, privacy-policy draft, signing template and Play Store checklist.

A compiled APK is not included because this execution environment does not provide Android SDK/Gradle. Do not treat the ZIP itself as an APK.

Use Android Studio with SDK 35/JDK 17 and build `assembleRelease` after configuring your private signing key.
