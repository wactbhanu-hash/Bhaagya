# भाग्य V7 — Verified Rule Library

V7 introduces the first rule-library pipeline, but it deliberately ships with only SAFE, NON-PREDICTIVE demonstration rules until each historical astrology rule has been checked against a specific edition.

A production astrology rule must include:
- source ID
- exact work/author/edition
- chapter/verse locator
- legal-use status
- normalized condition
- interpretation
- reviewer status

No historical claim is promoted to production merely from a web page or scan.

## Rule categories planned
1. Planet in sign
2. Planet in house
3. House lord placement
4. Nakshatra
5. Dignity
6. Aspects
7. Yogas
8. Dasha activation
9. Transit activation

## Confidence model
The app reports:
- Calculation confidence: quality of astronomical inputs/calculation.
- Source confidence: verification state of the rule.
- Interpretation confidence: consistency of matched rules.

These are NOT probabilities of a future event.
